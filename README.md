# Polycrisis (archived)

This repository has been merged into **[IainDM/Earth4All.jl](https://github.com/IainDM/Earth4All.jl)**.

The MCP server now lives at `earth4all-mcp/` inside that repo, alongside the
Julia model it wraps. Path defaults have been updated so the server finds the
colocated model source automatically — no submodule or `EARTH4ALL_SRC`
environment variable needed in the default layout.

For history, see this repo's prior commits or the merge commit on the unified
repo.
